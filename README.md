# PixelTools – browser-based image tools

A static website with free image tools: compress, resize, convert (JPG/PNG/WebP) and images to PDF. All processing runs in the visitor's browser; there is no server and no database.

## Stack
Plain HTML/CSS/JavaScript generated by one dependency-free Node script (`build.js`). Chosen because the site is static, loads fast, ranks well, and hosts free. You need only [Node.js 18+](https://nodejs.org).

## Commands
```
node build.js     # generate the site into dist/
node test.js      # check titles, links, sitemap, JSON-LD, PDF/ZIP writer
npx serve dist    # preview locally (or: python3 -m http.server -d dist)
```

## Change your brand
Edit `site.config.js`: name, URL, contact email, legal name, colors, AdSense ID. Then rebuild. Set `SITE_URL=https://yourdomain.com` when building, or edit `url` in the file.
The header logo splits the name after "Pixel" for styling; edit `layout()` in `build.js` if your name differs.

## Add a tool
1. Add an entry to `tools.config.js` (copy a similar one; `mode` is `compress`, `resize`, `convert` or `pdf`).
2. For a brand-new kind of processing, add a mode to `src/engine.js`.
3. `node build.js`. The page, navigation, footer, sitemap and related links update automatically. The build fails if a related tool or guide slug is wrong.

## Content
Guides live in `guides.config.js`. Legal pages are in `build.js` (`L`), starter text only; have them reviewed.

## Deploy (Cloudflare Pages, free)
1. Push this folder to GitHub: `git remote add origin <your repo URL>` then `git push -u origin main`.
2. Cloudflare dashboard → Workers & Pages → Create → Pages → connect the repo.
3. Build command `node build.js`, output directory `dist`, environment variable `SITE_URL=https://yourdomain.com`.
4. Add your custom domain under the project's Custom domains tab and follow the DNS instructions shown.
`dist/_headers` sets security headers. **If you add AdSense**, the Content-Security-Policy there must be relaxed to allow Google's script and frame domains.

## Search Console
Add your domain at search.google.com/search-console, verify via DNS, submit `https://yourdomain.com/sitemap.xml`, and use URL Inspection on key pages.

## AdSense
Replace `pub-XXXXXXXXXXXXXXXX` (env var `ADSENSE_ID` or `site.config.js`). Update the privacy and cookie pages for ads and add a consent banner where required.

## Limits and not included
- Inputs: JPG, PNG, WebP. 50 MB and 40 megapixels per image; 100 files.
- **HEIC to JPG and PDF to image are not included.** They need WASM libraries (e.g. libheif, pdf.js) that could not be installed offline here. Adding them means vendoring the library and a new mode in `engine.js`.
- WebP output depends on the browser being able to encode WebP.

## Troubleshooting
- Wrong URLs in sitemap/canonicals: set `SITE_URL` and rebuild.
- A tool does nothing: open the browser console; check that `lib.js` and `engine.js` loaded.
